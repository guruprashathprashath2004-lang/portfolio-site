Project screenshot folders
==========================

Each folder below matches the id of a project in js/projects.js.
Put Homepage.png first. Put any additional screenshots in the same folder and
add each exact filename to that project's screenshots array in js/projects.js.

The site is static, so it cannot automatically list files from these folders.
Only filenames in the screenshots array are displayed. Names are case-sensitive.
The expand button appears even when Homepage.png is the only listed screenshot.
