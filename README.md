# Rajendran Guruprashath Portfolio

A personal portfolio website for Rajendran Guruprashath (Dhanu), showcasing software engineering projects, skills, education, and contact details.

## Highlights

- Responsive portfolio landing page
- Project explorer with screenshots and GitHub links
- Skills, education, and contact sections
- Downloadable CV
- Works as a static site for GitHub Pages

## Run locally

1. Open the project folder.
2. Run the screenshot generator batch file:

   `update-screenshots.bat`

3. Start a local web server from the project root:

   `python -m http.server 8000`

4. Open `http://localhost:8000` in your browser.

## Files

- `index.html` — site markup
- `css/style.css` — styling
- `js/main.js` — UI interactions
- `js/projects.js` — project information
- `assets/` — portfolio images and CV

## Deployment

This site is designed to be deployed as a static website on GitHub Pages or any static host.
